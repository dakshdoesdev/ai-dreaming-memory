# Experiment status

The implementation, four-paper collection, source-support audit and offline smoke test are complete. A live DeepSeek-V4-Flash comparison on AMD Token Lab is currently running. No live score is claimed in this status file.

The initial study scope is the first six chunks of each of four papers, with 12 fixed questions and three retrieval arms. See [the preregistered protocol](../docs/EXPERIMENT.md), [corpus manifest](corpus-manifest.json) and [extraction spot audit](EXTRACTION_AUDIT.md).

The offline smoke report is a plumbing test using an unintelligent test double, not evidence that memory improves performance. Full paper texts, databases, API credentials and private logs are excluded from this repository.
